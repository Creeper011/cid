# Cid (Discord Bot)

Cid is a multifunctional Discord bot that provides random audio playback, utility commands, and download functionalities. Inspired by the character Sid from Ice Age, Cid brings some randomness and fun to voice channels.

### Features

•	Random audio playback in voice channels
•	Download tools (SoundCloud, YouTube, etc.)

### Getting Started

1.	Clone the repository:

```bash
git clone https://github.com/Creeper011/cid.git
```


2.	Install dependencies:
Ensure you have Python installed, then run:

```bash
pip install -r requirements.txt
```


3.	Environment setup:
Create a .env (in ./config) file with your Discord bot token and other necessary configurations:

```bash
TOKEN=your_token_here
```


4.	Run the bot:
Start the bot using:

```bash
python cide.py
```
